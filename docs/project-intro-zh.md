# 基于 TC264 的 GPS/视觉导航智能车项目

## 一、项目概述

本项目是一辆基于 **Infineon AURIX TC264D** 微控制器的多功能智能车，使用 **逐飞科技 (SEEKFREE) 开源库** 作为底层驱动框架。车辆集成了 **GPS 导航**、**摄像头视觉循迹**、**IMU 惯性导航** 和 **无刷电机驱动**，可通过 IPS200 屏幕上的多级菜单进行参数配置与模式切换。

项目目标是实现自主导航小车，能够在户外环境中按照预设 GPS 航点自主行驶，同时结合摄像头图像处理进行道路循迹辅助。

## 三、软件架构

### 3.1 开发环境
- **IDE**: AURIX Development Studio (ADS) v1.10.2
- **编译器**: Tasking C/C++ Compiler
- **PCB 设计**: Altium Designer (两个 .epro 工程文件)
- **底层库**: 逐飞科技 zf_common / zf_driver / zf_device / zf_components

### 3.2 自定义代码模块 (code/ 目录)

| 文件 | 功能 |
|------|------|
| `GPS.c / GPS.h` | GPS 数据解析、航点存储(Flash)、多路径管理(3条子路径,每条最多16个航点)、航向跟踪导航 |
| `Menu.c / Menu.h` | 多级菜单系统(3层深度), 通过状态机表驱动实现, 覆盖 GPS/IMU/舵机/电机/摄像头等全部参数调节 |
| `Image.c / Image.h` | 摄像头图像处理: OTSU 自适应二值化、中线提取、转向控制输出 |
| `Agorithm.c / Agorithm.h` | PID 控制算法 (位置式/增量式), 用于 GPS 导航和惯性导航的闭环控制 |
| `GL_Math.c / GL_Math.h` | 自实现数学库: sin/cos/asin/atan2/sqrt, IIR 低通滤波器, 快速平方根 |
| `Common_Peripherals.c / .h` | 外设封装: 蜂鸣器、按键扫描、舵机控制、BLDC 电机控制、LED、RC 遥控输入 |
| `IMU_1.c / IMU_1.h` | IMU963RA 数据读取与处理 |
| `BD_ctrl.c / BD_ctrl.h` | 北斗/导航控制模块 |

### 3.3 中断调度架构

系统使用 **CCU6 定时器中断** 实现多任务调度:

| 中断 | 周期 | 任务 |
|------|------|------|
| CCU60_CH0 | 20ms | IMU 数据采集与姿态解算 |
| CCU60_CH1 | 5ms | 按键扫描 |
| CCU61_CH0 | 5ms | GPS 导航 / 惯性导航计算 |
| CCU61_CH1 | 5ms | (预留) |
| UART3_RX | - | GNSS 数据接收回调 |

### 3.4 主循环逻辑

```
core0_main() {
    初始化: GPS, 蜂鸣器, 舵机, 按键, BLDC, IPS200 显示屏, IMU963RA
    启动定时器中断 (CCU60/CCU61)
    while(1) {
        GPS_parse();   // GPS 数据解析
        Menu();        // 菜单界面刷新
    }
}
```

## 四、核心功能实现

### 4.1 GPS 航点导航
- 支持存储 **3 条独立路径**, 每条最多 **16 个航点**
- 航点坐标 (经纬度) 通过 Flash 持久化存储, 断电不丢失
- 导航算法计算当前位置到目标航点的 **距离** 和 **方位角**, 通过 PID 控制舵机转向
- 到达航点后自动切换下一个目标

### 4.2 摄像头视觉循线
- MT9V03x 灰度摄像头, 188x120 分辨率
- **OTSU 大津法** 自适应二值化, 适应不同光照
- 提取赛道中线, 计算偏差 → PID → 舵机转向
- DMA + 中断驱动图像采集, 保证实时性

### 4.3 IMU 惯性导航
- IMU963RA 九轴传感器, 20ms 周期采样
- 提供航向角信息, 辅助 GPS 导航在信号弱时保持方向

### 4.4 菜单系统
- 三级菜单结构, 通过状态机表驱动
- 支持实时调参: PID 参数、舵机中值/范围、电机速度、GPS 航点录入等
- IPS200 彩屏显示, 按键上下选择 + 确认

## 五、遇到的问题与解决

### 问题 1: GPS 数据解析不稳定
- **现象**: GPS 模块在城市高楼或树荫下信号丢失, 导致导航失控
- **解决**: 在导航算法中加入信号质量判断; 信号弱时切换到 IMU 惯性导航模式维持航向

### 问题 2: 摄像头图像受光照影响大
- **现象**: 室内外光线差异大, 固定阈值二值化效果差
- **解决**: 改用 OTSU 自适应阈值算法, 根据图像直方图自动计算最佳分割阈值

### 问题 3: PID 参数调试困难
- **现象**: GPS 导航和摄像头循线的 PID 参数需要反复调试, 每次烧录耗时
- **解决**: 开发了 IPS200 菜单系统, 支持运行时实时修改 PID 参数, 通过 Flash 保存

### 问题 4: 数学函数库依赖大
- **现象**: 标准 math.h 在嵌入式环境下占用较多 Flash/RAM
- **解决**: 自行实现了轻量级数学库 (GL_Math), 包含快速 sin/cos/atan2/sqrt, 满足精度需求的同时大幅减小代码体积

### 问题 5: 多中断优先级冲突
- **现象**: IMU、按键、导航计算同时触发中断时偶发卡死
- **解决**: 合理分配中断优先级, 开启中断嵌套 (`interrupt_global_enable(0)`), 将耗时计算放在主循环

## 六、使用 MiMo Code / AI 辅助开发

在本项目开发过程中, AI 工具 (MiMo Code) 在以下环节提供了帮助:

1. **代码分析与理解**: 利用 AI 快速解析逐飞开源库的底层驱动接口 (如 GTM PWM、ASCLIN UART、VADC 等), 缩短了查阅 Infineon 官方手册的时间
2. **PID 算法优化**: 通过 AI 辅助分析增量式 PID 和位置式 PID 的适用场景, 优化了导航控制策略
3. **图像处理算法**: AI 辅助理解 OTSU 大津法原理, 并生成了针对嵌入式平台优化的二值化实现
4. **数学库实现**: 自定义三角函数和快速平方根的算法选型和精度验证
5. **PCB 设计审查**: 利用 AI 分析 Altium Designer 工程中的元器件选型和布局合理性
6. **Bug 排查**: 遇到中断冲突、通信异常等问题时, AI 辅助分析代码逻辑快速定位
